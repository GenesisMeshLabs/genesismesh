# Trust Architecture and Governed Changes (Phases H–J, N)

From v0.26.0 to v1.7.0 the project built the trust architecture cycles,
hardened them against adversarial behavior, carried them to a stable 1.0
contract, and then made every governed change leave a signed record.

| Phase | Versions | Theme |
|-------|----------|-------|
| {doc}`H <phase-h>` | v0.26.0 – v0.31.0 | Governed Relationships |
| {doc}`I <phase-i>` | v0.32.0 – v0.37.0 | Runtime Trust Layer |
| {doc}`J <phase-j>` | v0.38.0 – v1.1.1 | Third Trust Cycle and 1.0 |
| {doc}`N <phase-n>` | v1.2.0 – v1.7.0 | Governed Changes and Edge Trust |

Phases K, L and M were the TypeScript, Go and .NET SDK releases (v0.53.0 to
v0.55.0). They have no page of their own; {doc}`../history` tells them.
