# Changelog

The complete Genesis Mesh changelog is maintained at the repository root as
`CHANGELOG.md`. It covers every release from v0.1.0 through the current version,
organized by version with Added / Changed / Fixed / Removed sections.

[View CHANGELOG.md on GitHub](https://github.com/GenesisMeshLabs/genesismesh/blob/main/CHANGELOG.md)

Changes not yet released are in `changelog.d/<version>/`, one file per
change, until the release folds them into `CHANGELOG.md`.

---

- [Go SDK changelog](https://github.com/GenesisMeshLabs/sdk-go/blob/main/CHANGELOG.md)

- [Rust SDK, verifier and edge agent changelog](https://github.com/GenesisMeshLabs/sdk-rust/blob/main/CHANGELOG.md):

- Gateway: the gateway has no changelog file; its release notes are on its
