# Verification

Checking the NA's records without asking the NA: decisions, evidence
exports, the NA's key history and audit packs. The verifiers are part of the
SDK and follow the Python reference; they check records against keys and
anchors you hold.

- {doc}`offline-verification`: verifying decisions and evidence exports
  without the NA, and the canonical JSON rules
- {doc}`audit-packs` (1.5.0): the NA key history and key succession, and
  audit packs verified offline
