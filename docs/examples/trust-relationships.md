# Relationships & Agreements

Dual-signed agreements, attenuable delegation chains, relationship context,
declarative boundary policies, attestation-backed evaluation, and trust
evidence records.

- {doc}`relationship-agreement` — a dual-signed AgreementRecord via offer, counter and acceptance
- {doc}`delegation-chain` — delegating a strict subset of an agreement's rights
- {doc}`relationship-context` — a ContextRecord evaluated by the BoundaryEngine into a signed decision
- {doc}`declarative-boundary-policy` — signed, versioned gate policies; opt-in
- {doc}`attestation-backed-evaluation` — evaluating a request against a membership attestation; opt-in
- {doc}`trust-evidence` — a signed TrustEvidence record verified offline
