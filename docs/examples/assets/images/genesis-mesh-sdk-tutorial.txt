==> Set up a governed local NA (port 18455)
$ genesis-mesh init --config local/genesis-mesh.toml --home local/.genesis-mesh --network-name MY-PROJECT-DEV --na-endpoint http://127.0.0.1:18455 --na-port 18455 --env-file local/na.env
Note: genesis block contains a placeholder policy hash. Replace PolicyManifestRef.hash with the SHA-256 of your policy document before production use.
Warning: the root private key was written to local\.genesis-mesh\keys\root.key, next to the NA key (local\.genesis-mesh\keys\na.key). Whoever holds both can replace the NA's key history. For anything but local use, move the root key offline and delete it from this host (see the root key ceremony in the operations docs); NA_DEPLOYMENT=managed refuses to start while it is there.
