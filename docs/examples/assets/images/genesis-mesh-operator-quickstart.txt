==> 1. Initialize a named sovereign and write its NA settings file
$ genesis-mesh init --home sovereign --config sovereign/genesis-mesh.toml --network-name EXAMPLE-NB --na-endpoint http://127.0.0.1:18452 --na-port 18452 --env-file sovereign/na.env
Note: genesis block contains a placeholder policy hash. Replace PolicyManifestRef.hash with the SHA-256 of your policy document before production use.
Warning: the root private key was written to sovereign\keys\root.key, next to the NA key (sovereign\keys\na.key). Whoever holds both can replace the NA's key history. For anything but local use, move the root key offline and delete it from this host (see the root key ceremony in the operations docs); NA_DEPLOYMENT=managed refuses to start while it is there.
Initialized Genesis Mesh config: sovereign\genesis-mesh.toml
Genesis block: sovereign\genesis.signed.json
Operator key: sovereign\keys\operator.key
NA settings: sovereign\na.env (start with: genesis-mesh na start --env-file sovereign\na.env)

==> 2. Check the host: init wrote the root key next to the NA key
$ genesis-mesh na doctor --env-file sovereign/na.env
!no FAIL  root_key_absent: the root private key is in C:\gm-demo\gm-quickstart-9ioo5fh3\host\sovereign\keys\root.key: move the root key offline (root key ceremony)
WARN  deployment: NA_DEPLOYMENT is local: the NA does not refuse to start with the root key on its host; set NA_DEPLOYMENT=managed in production
!ok OK    na_key: NA key 1 of 1 signs now (the genesis key's valid_to is not enforced)
!ok OK    retention_archive: retention removes only what an archive covers
!no Result: FAILED
==> 3. Move the root key off the host (here: outside the NA's directories), then check again
$ mv sovereign/keys/root.key ../offline-media/ && ls ../offline-media
root.key
$ genesis-mesh na doctor --env-file sovereign/na.env
!ok OK    root_key_absent: the root private key is not where the NA's files live
WARN  deployment: NA_DEPLOYMENT is local: the NA does not refuse to start with the root key on its host; set NA_DEPLOYMENT=managed in production
!ok OK    na_key: NA key 1 of 1 signs now (the genesis key's valid_to is not enforced)
!ok OK    retention_archive: retention removes only what an archive covers
!ok Result: OK
