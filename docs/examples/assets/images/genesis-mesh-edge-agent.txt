==> 3. The NA is stopped: break-glass, only with a justification
$ kill $NA_PID
$ curl -s --unix-socket /tmp/gm-edge-1wc_py7m/agent.sock -X POST http://localhost/v1/authorize -d '{"capability": "secret.rotate", "request_parameters": {"lifetime_days": 30}, "resource_id": "edge:site7-17/kv/db", "resource_action": "rotate"}' | tee answer.json | python -c "import json,sys; a=json.load(sys.stdin); print('allowed', a['allowed'], 'authority', a.get('authority'), 'code', a.get('code'))"
!no allowed False authority None code justification_required
$ curl -s --unix-socket /tmp/gm-edge-1wc_py7m/agent.sock -X POST http://localhost/v1/authorize -d '{"capability": "secret.rotate", "request_parameters": {"lifetime_days": 30}, "resource_id": "edge:site7-17/kv/db", "resource_action": "rotate", "justification": "INC-4471: key leaked in a log, rotate now"}' | tee answer.json | python -c "import json,sys; a=json.load(sys.stdin); print('allowed', a['allowed'], 'authority', a.get('authority'), 'code', a.get('code'))"
