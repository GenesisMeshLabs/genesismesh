==> 1. History, root signature, new-key proof, submit
$ genesis-mesh keygen network-authority --output na-2 --key-id na-2
Public key (base64): 1irbE0Jq3YVg6kjmzkt1R66vpAanvRTC3+9PsJeNAIc=
$ genesis-mesh na succession history --na http://127.0.0.1:18451 --out history.json
Key history of SUCCESSION-DEMO: 1 key(s); saved to history.json
$ genesis-mesh na succession sign --history history.json --root-key .genesis-mesh/keys/root.key --new-public-key na-2.pub --new-key-id na-2 --effective-in 70 --out succession.json
Succession 8275ca6e-3153-4c03-b1b9-726bb06ce6b4: key 2 (na-2) takes effect at 2026-10-22T00:50:27+00:00 and is valid until 2027-10-22T00:50:27+00:00.
$ genesis-mesh na succession prove --file succession.json --new-key na-2.key --out succession.json
Signed by the new key na-2; written to succession.json. Submit it with 'na succession submit'.
$ genesis-mesh na succession submit --na http://127.0.0.1:18451 --file succession.json --config genesis-mesh.toml
!ok Recorded: key 2 (na-2) takes effect at 2026-10-22T00:50:27Z. Restart the NA with the new key then; the old key signs nothing after it.

NA_KEY_ID=na-2

==> 4. Records signed by both keys verify from the root key
$ curl -s http://127.0.0.1:18451/na/key-history > key-history.json && ops-demo-client admin GET /admin/evidence/export > export.jsonl && ops-demo-client admin GET /admin/evidence/executor-keys > executor-keys.json
$ genesis-mesh evidence verify-export --file export.jsonl --key-history key-history.json --root-key .genesis-mesh/keys/root.pub --executor-keys executor-keys.json

Decisions  : 2
Executions : 2
