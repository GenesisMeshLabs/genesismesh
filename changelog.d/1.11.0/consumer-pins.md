### Changed

- **The Interoperability run uses pinned SDK releases.** It checks out the Go, TypeScript and .NET SDKs at the refs in `contract/consumer-pins.json` (a release tag, or a commit on the SDK's `main`), checked on GitHub by `scripts/consumer_pins.py`, instead of the SDK branches named like the core branch. A core pull request is tested against the same SDK code in its own run, in the merge queue and on `main`, so a merge in an SDK repository can no longer turn a core check red. The pins start at 1.10.1. The run no longer compares the SDKs' copies of the conformance vectors with the core's: from 1.11.0 each SDK checks its copies against the contract bundle it pins. A pin change runs the Interoperability job ("Jobs a pull request may skip" in `docs/development/testing.md`).
